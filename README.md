# Izuchukwu: portfolio

React + Vite + Tailwind CSS v4 + React Router. Plain JavaScript.

## Run (PowerShell)

```powershell
cd $HOME\izuchukwu-portfolio
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in .\dist
npm run preview  # serve the build locally
```

## Where things live

- `src/data/site.js`: name, pitch, email, WhatsApp, socials, about text, contact copy, n8n webhook URL
- `src/data/projects.js`: all projects (home grid + `/projects/:slug` pages)
- `src/data/services.js`: What I do, How I work, Tech I use
- `src/data/testimonials.js`: client quotes (currently SAMPLES, see below)
- `src/index.css`: design tokens (4-color palette: lime, sky, amber, coral; fonts; spacing; motion) and global styles
- `src/components`, `src/sections`, `src/pages`: one component per file, each with its own BEM CSS file
- `public/images`: put real screenshots and your portrait here
- `design-system/`: design system notes generated by the ui-ux-pro-max skill
